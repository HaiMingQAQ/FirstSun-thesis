# 门店人工文字咨询开发记录

## 复用与缺口

复用现有会员认证、租户拦截器、员工与门店数据权限、药师资质校验、MyBatis 和前后台请求框架。通用商城客服模块未在当前服务中启用，且其管理员广播缺少门店接待边界；不直接向药店开放。新增仅为药店门店会话、文字消息、后台领取回复和已读位置，不重复开发商城、员工或会员模块。

新增 SQL42 位于 41 之后，两个表不含账号或合成消息。通用菜单挂到既有 `/pharmacy-base`，不自动授予角色权限。管理员须向指定本店在职员工授予 `pharmacy:consultation:query` 与 `pharmacy:consultation:reply`；药师会话额外检查岗位及有效执业资质，客服无诊断或开方能力。租户管理员亦须有在职员工门店身份才能接待。

## 行为与权限

同一租户／会员／门店／咨询类型复用一条会话，未领取时明确等待接待，不自动回复或承诺立即有人在线。领取用数据库行锁，只有一名接待人员获得会话；已领取会话只有本人和顾客可访问，其他店员不能查看或回复。医生咨询仅说明原型模拟且无真实服务，不提供可办理入口。

正文为最多 1000 字的纯文字，前端转义展示，不支持文件、富文本、处方审核或自动流转。处方图片沿用私有处方入口。发送以会话／发送者／客户端请求编号去重，重复编号内容变化拒绝。发送结果未知时沿用原编号重试，不显示假成功。已读只更新已获取消息的单调位置，不能传其他会话消息编号或清除随后新消息的未读。

查询有 20 条会话分页和 50 条消息分页，后台先领取后回复。前端可见时每 5 秒轮询，隐藏／卸载时停止；账号改变清空顾客消息并丢弃旧响应。数据库事务与唯一键足以满足当前并发和未读需求，无新增 Redis 服务或用途。咨询路径与矩阵参数变体按私有业务处理，访问和错误日志不记录正文／返回消息。

## 边界与剩余风险

仅在新建的本地独立库验证，未连接云端或旧业务库。人工文字咨询不提供医疗诊断、医生开方、即时接听保证、语音／视频或真实微信通知推送。当前领取不提供跨员工转派或离职自动交接，需运营安排；消息保留期限、存储配额与生产备份／加密策略部署前另行确定。微信工具、真机、真实微信登录、远程部署均未验证。待 02 集中审查后再安排提交准备。

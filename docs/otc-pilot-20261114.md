供 12 独立复验：

1. 工作区运行 `node scripts/tests/otc-pilot.test.cjs`。它对照 Git 基线 `a6d232e1`，验证原45件商品的档案、分类和旧语料，检查新编码、OTC标志、演示库存、五段语料及种子防重结构。测试在本地运行。
2. 当前版本复验按 [本地初始化文档](local-demo-install.md)执行。空库首次安装得到 59 件目录商品，另保留 2 件流程夹具，共 61 条档案；仅新 14 款启用且线上可售，旧 47 条停用、离线。旧45件库升级新增14款，旧50件库升级新增9款，已有商品启用、上架状态沿用。再次执行保留历史关联和已变化的库存，每个新 ID 各有一条开账批次、一条货位库存和一条开账流水。同编码、同 ID 或同租户同批准文号若被其他档案占用，应停止。
3. 若另行获准重建演示 RAG 索引，按初始化文档使用演示账号调用重建入口，再核验本批 5 个编码都命中独立药品资料，查询仍按演示租户过滤。当前仅验证语料和目录映射，未执行数据库初始化、线上检索、订单、支付或外部 AI 请求。
